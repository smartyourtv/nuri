# Nuri

Nuri is a free helper app for older adults: it reads letters and
labels aloud, explains them in plain words, helps with medicine
reminders and everyday confusion, and keeps family in the loop —
on the phone, in plain sight.

- [Privacy Policy](privacy-policy.md)
- Source code: this repository (GPL-3.0-or-later, with a linking
  exception for the Google libraries — see `LICENSE` and
  `LINKING-EXCEPTION` in the repository root).
- Terms of use: `TERMS.md` in the repository root.

> Nuri is a free helper app — not a medical device. It never calls
> 911 by itself; in an emergency, call 911. Medicine reminders are
> memory aids based on a schedule you enter, not medical advice.
> Safety features are aids that can miss things — please don't rely
> on Nuri alone for anyone's safety.
